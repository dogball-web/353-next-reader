# 353：下一位閱讀者

《誠大語言文本系怪異紀錄》系列番外篇，v0.4 雛形試玩版。

2012年的教材校對、訊息與手寫紀錄，和2018年的353語言教室維修工作。

## 遊玩

完整下載後，使用瀏覽器開啟 `index.html`。也可交由靜態網站服務託管此資料夾。
不需安裝套件或輸入真實帳號密碼。Fine為遊戲內虛構軟體。

進度儲存在目前瀏覽器；時間以分鐘顯示。教材分數不影響劇情。
本版尚無線上通關統計，正式劇情與結局仍在製作中。

## 專案內容

- `index.html`：遊戲入口
- `style.css`：桌面、聊天及調查介面
- `data.js`：教材與信件資料
- `app.js`：流程、存檔及通關卡
- `assets/`：遊戲照片
- `作者閱讀_含答案.md`：包含謎題答案與劇情草稿，遊玩前請避免閱讀

完整操作與版本說明見 `README.txt`。

## v0.4
視覺小說式角色對話、不同年代的維修與會面、三份草稿的句子指認，以及三個收尾。角色姓名使用固定配色。Fine頭貼為河童小畫家簡筆圖、鵪鶉蛋與虛構夫妻合照。

手機請使用試玩網站；iOS檔案預覽可能不執行本機HTML中的程式。

## 流程檢查

執行 `node tests/flow.cjs`。測試使用模擬DOM與時鐘，涵蓋訊息順序、三個結局、重試及存檔，不等同實際瀏覽器視覺驗證。
